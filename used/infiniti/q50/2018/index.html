Buying a used 2018 Infiniti Q50? Check these 3 recalls first

3 NHTSA recalls · 42 owner complaints on file

This model year has three recalls: a high-severity software flaw that can stall the engine, a high-severity driveshaft breakage risk, and a medium-severity backup camera display issue. NHTSA shows 42 owner complaints (unverified reports) for this vehicle, including 1 crash and 1 fire, with no reported injuries. Engine problems are the top complaint category at 17, followed by air bags (8), fuel/propulsion system (6), and electrical system (5).

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the engine-stall software update and driveshaft recall have been completed
  3. Test the backup camera display for consistent operation
  4. Ask about engine performance history, since engine issues are the top complaint category
  5. Open recalls are repaired free at any Infiniti dealer, whoever owns the car — an open recall is a to-do item, not a bill.
