Buying a used 2019 Honda Clarity Plug-In Hybrid? Check these 2 recalls first

2 NHTSA recalls · 42 owner complaints on file

The 2019 Clarity Plug-In Hybrid has two recalls: Honda's fuel-pump defect that can stall the engine, and a medium-severity recall for rear seat belts that may not lock properly — relevant if child seats ride in back. Owners filed 42 unverified NHTSA complaints, a small count led by engine (10), vehicle speed control (9) and electrical system (7), and including two crashes and three injuries. Nothing in that spread points to a single dominant failure pattern.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the fuel-pump recall was completed and ask about any stalling episodes.
  3. Test each rear belt's locking retractor, especially if you will install a child seat.
  4. Ask whether the car has shown engine or electrical warnings, given those complaint areas.
  5. Open recalls are repaired free at any Honda dealer, whoever owns the car — an open recall is a to-do item, not a bill.
