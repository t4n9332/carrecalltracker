Buying a used 2018 Honda Accord Hybrid? Check these 4 recalls first

4 NHTSA recalls · 115 owner complaints on file

Four recalls, all safety-relevant but none flagged stop-driving: front seat belts that may not latch, a fuel pump that can fail and stall the engine, a seat sensor tied to unintended airbag deployment, and a software glitch that disables safety systems. Owner complaints number 115, unverified reports to NHTSA, spread across engine, electrical and fuel/propulsion, with one fire, three crashes and two injuries reported among them.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Run the VIN for open recalls, especially the fuel pump and seat sensor remedies
  3. Latch and tug each front seat belt several times to confirm it engages
  4. Ask whether driver-assist warning lights have appeared and if the safety-system software update was applied
  5. Open recalls are repaired free at any Honda dealer, whoever owns the car — an open recall is a to-do item, not a bill.
