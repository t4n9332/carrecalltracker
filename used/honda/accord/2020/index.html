Buying a used 2020 Honda Accord? Check these 5 recalls first

5 NHTSA recalls · 356 owner complaints on file

The recall list mirrors 2019 minus the seat belt latch item: two fuel-pump campaigns that can stall the engine, a passenger seat sensor that may crack with airbag risk, a second seat sensor airbag recall, and a medium software recall that can disable safety systems. No stop-driving or park-outside warnings. Owners filed 356 unverified NHTSA complaints — 14 crashes, two fires, 11 injuries — led by forward collision avoidance, engine, service brakes and electrical.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Verify both fuel-pump recalls and the seat sensor repairs by VIN
  3. Ask whether the safety-system software update has been applied
  4. Have the brakes inspected and note any warning lights on a test drive
  5. Open recalls are repaired free at any Honda dealer, whoever owns the car — an open recall is a to-do item, not a bill.
