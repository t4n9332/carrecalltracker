Buying a used 2024 Honda CR-V? Check these 2 recalls first

2 NHTSA recalls · 388 owner complaints on file

This model year carries two medium-severity recalls: tires missing a required date code marking and a steering gearbox that can cause difficulty steering. NHTSA has logged 388 owner complaints (27 crashes, 0 fires, 14 injuries) for this year, an unverified record, led by steering (124), unknown/other (67), and visibility/wiper and forward collision avoidance tied at 48 each.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Check tire DOT date codes against the recall notice
  3. Ask if the steering gearbox recall was completed and test steering behavior
  4. Test wipers/visibility and the forward collision avoidance system on a test drive
  5. Open recalls are repaired free at any Honda dealer, whoever owns the car — an open recall is a to-do item, not a bill.
