Buying a used 2020 Hyundai Nexo? Check these 4 recalls first

4 NHTSA recalls · 7 owner complaints on file · 2 park-outside

This model year has two critical recalls — hydrogen leak detection failure and fuel tank fire risk — both with a park-outside advisory, plus two high-severity recalls covering remote parking failure and a braking system issue. NHTSA has 7 owner complaints on file (unverified reports), with no crashes, fires, or injuries reported; fuel/propulsion system complaints lead at 5, followed by powertrain and engine at 2 each, and fuel system at 1.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm both hydrogen-related recalls have been completed
  3. Ask whether the remote parking recall was addressed
  4. Verify the braking system recall repair was performed
  5. Open recalls are repaired free at any Hyundai dealer, whoever owns the car — an open recall is a to-do item, not a bill.
