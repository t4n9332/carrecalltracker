Buying a used 2018 Nissan Frontier? Check these 2 recalls first

2 NHTSA recalls · 25 owner complaints on file

This model year has two recalls: a key ignition issue that may shut off the engine, shared with the Versa, and a backup camera image that can stay off. NHTSA logged 25 owner complaints (unverified reports), with no crashes, fires, or injuries reported. Electrical system issues lead at 5, followed by an unknown/other category (4), service brakes (4), and suspension (3). Complaint volume is moderate and spread across several systems rather than concentrated in one area.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the key/ignition recall has been repaired
  3. Test the backup camera display for a stable image
  4. Ask about any brake or suspension service history
  5. Open recalls are repaired free at any Nissan dealer, whoever owns the car — an open recall is a to-do item, not a bill.
