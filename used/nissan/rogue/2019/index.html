Buying a used 2019 Nissan Rogue? Check these 3 recalls first

3 NHTSA recalls · 332 owner complaints on file

This 2019 Rogue has three recalls, including two high-severity issues: wiring damage in hybrid models that can blow a fuse, and a folding key that can shut off the vehicle. A medium recall covers the backup camera image staying off. NHTSA has logged 332 owner complaints (unverified reports) for this model year, including 27 crashes and 28 reported injuries, with service brakes (124) and forward collision avoidance (99) as the most-cited categories.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the hybrid wiring and folding key recalls have been completed
  3. Have the brakes inspected given the complaint volume in this area
  4. Test the forward collision avoidance system and backup camera
  5. Open recalls are repaired free at any Nissan dealer, whoever owns the car — an open recall is a to-do item, not a bill.
