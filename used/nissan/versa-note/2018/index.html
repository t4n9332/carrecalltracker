Buying a used 2018 Nissan Versa Note? Check these 3 recalls first

3 NHTSA recalls · 3 owner complaints on file

Only three owner complaints are on file with NHTSA for this model year — too few to show a pattern — covering power train (2), suspension, service brakes and unknown/other; one mentions a crash, none report fires or injuries. The recall record carries more weight: two high-severity items, an airbag component that can fly into the cabin and a key that can shut the engine off, plus a backup camera image that may stay off.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the airbag recall was completed — ask for the repair order or run a VIN recall lookup.
  3. Ask whether the key/ignition recall was done and check that the engine doesn't cut out when the key is bumped.
  4. Test the backup camera over several reverse cycles for a missing image.
  5. Open recalls are repaired free at any Nissan dealer, whoever owns the car — an open recall is a to-do item, not a bill.
