Buying a used 2019 Lexus RX350? Check these 3 recalls first

3 NHTSA recalls · 65 owner complaints on file

This model year has three recall entries: a leftover tow hook that risks a fuel fire, and two entries covering a fuel pump that may fail and stall the engine. NHTSA lists none of these as stop-driving or park-outside. Owners have filed 65 complaints with NHTSA, described here as unverified reports, including 11 crashes and 3 injuries, with no fires noted. The most cited complaint areas are fuel/propulsion system (24 reports), forward collision avoidance (13 reports), service brakes (12 reports), and engine (10 reports).

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the tow hook recall and both fuel pump recalls have been completed
  3. Ask about the reported fuel/propulsion system complaints and any past crash repairs
  4. Ask about forward collision avoidance system function and service brake history
  5. Open recalls are repaired free at any Lexus dealer, whoever owns the car — an open recall is a to-do item, not a bill.
