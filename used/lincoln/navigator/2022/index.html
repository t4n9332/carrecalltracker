Buying a used 2022 Lincoln Navigator? Check these 14 recalls first

14 NHTSA recalls · 21 owner complaints on file

This model year carries an unusually long recall list for a Navigator — ten campaigns, six rated high, including three separate trailer-braking or trailer-light actions, leaking front brake lines, a fuel pump that can stall the engine, and front seat belts that can lock up. Lighting, rearview camera and moonroof deflector recalls round it out. NHTSA has 21 unverified owner complaints on file (three crashes, one fire, three injuries), clustered in electrical and brake systems.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Run the VIN through Ford/Lincoln recall lookup and confirm the brake-line and fuel-pump repairs were completed
  3. If you tow, test trailer brakes and trailer lights with a trailer actually hooked up
  4. On the test drive, check the rearview camera, front seat belt retractors, marker and daytime running lights, and the moonroof deflector
  5. Open recalls are repaired free at any Lincoln dealer, whoever owns the car — an open recall is a to-do item, not a bill.
