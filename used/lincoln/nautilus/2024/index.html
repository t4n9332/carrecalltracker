Buying a used 2024 Lincoln Nautilus? Check these 7 recalls first

7 NHTSA recalls · 22 owner complaints on file

This model year has seven recall campaigns, including a critical block heater overheating risk, high-severity recalls for power windows that may not reverse and a software bug that can blank displays, plus related power-window pinch recalls and a camera/ADAS loss issue. NHTSA received 21 owner complaints (unverified reports), including 2 crashes and 1 injury; complaints are spread across an unspecified category and electrical system (5 each), with visibility and service brakes at 3 each.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the block heater overheating recall was completed, especially if block heater equipped
  3. Test power windows for reverse and pinch-detection function
  4. Verify the display software bug and camera/ADAS recalls were addressed
  5. Open recalls are repaired free at any Lincoln dealer, whoever owns the car — an open recall is a to-do item, not a bill.
