Buying a used 2021 BMW 530E? Check these 2 recalls first

2 NHTSA recalls · 1 owner complaints on file

The 2021 530e carries the critical BMW/MINI plug-in hybrid battery fire recall and the backup camera image failure recall; neither is flagged stop-driving or park-outside. Only one owner complaint is on file with NHTSA, but it reports a fire, and the areas named are electrical system and fuel/propulsion system. That is a single unverified report rather than a pattern, though it does line up with the subject of the battery recall.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Verify the hybrid battery recall was performed and ask if the battery was replaced
  3. Ask about any charging, high-voltage or propulsion fault history
  4. Confirm the backup camera image appears every time you shift to reverse
  5. Open recalls are repaired free at any BMW dealer, whoever owns the car — an open recall is a to-do item, not a bill.
