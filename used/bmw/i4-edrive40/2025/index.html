Buying a used 2025 BMW I4 Edrive40? Check these 2 recalls first

2 NHTSA recalls · 6 owner complaints on file

Two recalls apply here. One is critical but described as affecting a single i4 eDrive40 with a loose battery cable connection, so a VIN check settles whether a given car is involved. The other is a broader software recall shared with the i5 and iX, where electric motor software can cut power. NHTSA lists six owner complaints, three involving crashes, no fires or injuries, clustered in forward collision avoidance, steering and power train. Complaints are unverified reports.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Run the VIN against NHTSA to see if the single-vehicle battery cable recall applies
  3. Verify the electric motor software recall update was installed at a dealer
  4. Test drive for power loss, steering feel, and false forward collision alerts
  5. Open recalls are repaired free at any BMW dealer, whoever owns the car — an open recall is a to-do item, not a bill.
