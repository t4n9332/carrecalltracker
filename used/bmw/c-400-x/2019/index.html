Buying a used 2019 BMW C 400 X? Check these 2 recalls first

2 NHTSA recalls · 1 owner complaints on file

This scooter has two high-severity recalls and both affect control: brake calipers that can corrode, shared with other BMW motorcycles, and a C400X-specific throttle that can freeze and stick open. Neither is flagged stop-driving. Only one owner complaint is on file with NHTSA — unverified, naming vehicle speed control and service brakes, with no crashes, fires or injuries. On a low-volume machine, a thin complaint file says little either way.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm both recalls were performed by a BMW Motorrad dealer
  3. Inspect the brake calipers for corrosion and test brake feel front and rear
  4. Check that the throttle snaps back smoothly, especially cold or damp
  5. Open recalls are repaired free at any BMW dealer, whoever owns the car — an open recall is a to-do item, not a bill.
