Buying a used 2021 BMW M3? Check these 3 recalls first

3 NHTSA recalls · 3 owner complaints on file

This 2021 M3 has three recalls: a possible loss of ABS function in the integrated brake system, a seat belt bolt issue, and a passenger seat belt retractor fault shared with other BMW/MINI/Toyota Supra models. NHTSA has 3 owner complaints on file for this model year, covering steering, suspension, airbags, and one uncategorized report, with no crashes, fires, or injuries reported. These are unverified owner-submitted reports. None of the recalls are marked stop-driving or park-outside.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the integrated brake system (ABS) recall has been completed
  3. Check whether the seat belt bolt recall repair was done
  4. Verify the passenger seat belt retractor fault has been fixed
  5. Open recalls are repaired free at any BMW dealer, whoever owns the car — an open recall is a to-do item, not a bill.
