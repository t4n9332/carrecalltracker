Buying a used 2024 Chrysler Voyager? Check these 7 recalls first

7 NHTSA recalls · 1 owner complaints on file

This model year's recall list leans heavily on occupant protection: two separate curtain-airbag recalls for pressure loss, a front-airbag non-deployment recall, and a missing seat stop part. A wheelchair-restraint recall applies only to Rollx-converted vans. Windshield bonding and loss of traction control with cruise on round it out. None carry stop-driving or park-outside warnings. Only one NHTSA owner complaint has been filed, in air bags — unverified, and a thin record for a recent van.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Run the VIN on NHTSA to confirm both curtain-airbag recalls and the front-airbag recall are closed
  3. Ask whether the seat stop part was installed, and get the repair order
  4. If it is a Rollx wheelchair conversion, verify the wheelchair restraint lock repair
  5. Open recalls are repaired free at any Chrysler dealer, whoever owns the car — an open recall is a to-do item, not a bill.
