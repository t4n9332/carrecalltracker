Buying a used 2019 Chrysler Pacifica? Check these 7 recalls first

7 NHTSA recalls · 354 owner complaints on file

This 2019 Chrysler Pacifica has 7 open recalls, including engine/power steering stalling issues, a wheelchair restraint lock defect, and three separate rearview camera display recalls; none require stop-driving or park-outside precautions. NHTSA has logged 354 owner complaints for this model year, unverified reports, with 11 crash reports, 3 fire reports, and 3 injury reports. Complaint areas are led by electrical system (116), engine (94), powertrain (86), and an unspecified category (64).

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm all 7 recalls, including the three camera-related ones, show completed repairs
  3. Test the rearview camera display for clarity and screen behavior
  4. Ask about any stalling or power steering loss incidents
  5. Open recalls are repaired free at any Chrysler dealer, whoever owns the car — an open recall is a to-do item, not a bill.
