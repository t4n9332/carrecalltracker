Buying a used 2025 Mercedes-Benz AMG G63? Check these 2 recalls first

2 NHTSA recalls · 3 owner complaints on file

The 2025 G63's recall record is short: two medium-severity items — a stability system warning light that displays incorrectly, and a front radar failure that disables automatic emergency braking. Notably, forward collision avoidance also appears twice among the three unverified owner complaints filed with NHTSA, alongside seat belts and vehicle speed control; one of those reports mentions an injury. No crashes or fires are recorded. For this model year the file is thin but concentrated on driver-assistance systems.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the front radar recall is done and test that emergency braking shows no fault on startup.
  3. Watch the instrument cluster for a stability system warning light during a cold start and test drive.
  4. Ask the seller about any forward collision avoidance or cruise control warnings they have experienced.
  5. Open recalls are repaired free at any Mercedes-Benz dealer, whoever owns the car — an open recall is a to-do item, not a bill.
