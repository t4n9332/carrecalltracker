Buying a used 2018 Mitsubishi Eclipse Cross? Check these 2 recalls first

2 NHTSA recalls · 19 owner complaints on file

This model year has two high-severity recalls tied to forward collision braking software and other safety system software issues on Mitsubishi vehicles. NHTSA has 19 owner complaints on file for this model year (unverified reports), including 1 crash, 1 fire, and 2 injuries. Electrical system complaints lead at 8, followed by service brakes (5), unknown/other (4), and engine (3).

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm both software recalls were completed
  3. Ask about the reported fire and how it was resolved
  4. Check service records for electrical system or brake issues
  5. Open recalls are repaired free at any Mitsubishi dealer, whoever owns the car — an open recall is a to-do item, not a bill.
