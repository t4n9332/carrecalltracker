Buying a used 2024 Chevrolet Malibu? Check these 2 recalls first

2 NHTSA recalls · 39 owner complaints on file

A light recall year: the same backup camera fix for a blank or distorted image, plus a paperwork recall for cars delivered with the wrong owner's manual. Neither is a stop-driving or park-outside item. NHTSA has 39 owner complaints on file — unverified reports — with 3 crashes, no fires and 1 injury. Electrical system leads the complaint areas at 17, ahead of back-over prevention at 10, which echoes the camera recall.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm by VIN whether the backup camera recall has already been performed.
  3. Check the glovebox manual is actually for a 2024 Malibu and not another GM model.
  4. Test electrical items on a cold start — screen, lights, windows, charge ports — since electrical tops the complaints.
  5. Open recalls are repaired free at any Chevrolet dealer, whoever owns the car — an open recall is a to-do item, not a bill.
