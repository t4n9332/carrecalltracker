Buying a used 2023 GMC Acadia? Check these 4 recalls first

4 NHTSA recalls · 43 owner complaints on file

This model year has four recalls: two high-severity items covering a half-shaft that can separate, plus a windshield problem, and a medium-severity issue with an unreadable tire size label. NHTSA has 43 owner complaints on file, unverified reports, with 3 crashes, 1 fire, and 4 injuries. Engine and power train each account for 12 complaints, electrical system for 9, and an unknown/other category for 8, with drivetrain-related recalls and complaints appearing as the most reported combination.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the half-shaft separation recall has been completed
  3. Ask about the windshield recall and any replacement performed
  4. Check the tire size label for legibility and accuracy
  5. Open recalls are repaired free at any GMC dealer, whoever owns the car — an open recall is a to-do item, not a bill.
