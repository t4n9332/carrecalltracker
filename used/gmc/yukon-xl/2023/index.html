Buying a used 2023 GMC Yukon XL? Check these 4 recalls first

4 NHTSA recalls · 211 owner complaints on file

Three high-severity recalls stand out: rear suspension bolts that can break, a missing brake fluid level warning, and possible 6.2L V8 engine failure, plus a lower-severity daytime running light issue. None requires parking outside or stopping driving. Engine is again the leading complaint category — 142 of 211 unverified NHTSA owner complaints — followed by powertrain and electrical. Those reports include 2 crashes and 13 injuries, the highest injury count among these Yukon XL years.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Have the rear suspension bolts inspected and confirm the recall repair was done
  3. Confirm the brake fluid warning software update was applied
  4. Ask if the truck has the 6.2L V8 and whether any engine work has been performed
  5. Open recalls are repaired free at any GMC dealer, whoever owns the car — an open recall is a to-do item, not a bill.
