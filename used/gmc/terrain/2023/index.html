Buying a used 2023 GMC Terrain? Check these 2 recalls first

2 NHTSA recalls · 38 owner complaints on file

This model year carries two recalls: an airbag sensor issue shared with the Chevrolet Equinox, and a child seat anchor issue where a coating can block the lower anchors, also shared with the Equinox. NHTSA has logged 38 owner complaints (unverified reports) for this vehicle, including 2 crashes, 1 fire, and 1 injury. The largest complaint categories are engine (14) and fuel/propulsion system (14), followed by power train (7) and an unknown/other category (7).

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the airbag sensor recall has been completed
  3. Confirm the child seat anchor coating recall has been completed
  4. Ask about any engine or fuel system problems the seller has experienced
  5. Open recalls are repaired free at any GMC dealer, whoever owns the car — an open recall is a to-do item, not a bill.
