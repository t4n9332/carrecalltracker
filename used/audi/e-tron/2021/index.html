Buying a used 2021 Audi E-TRON? Check these 9 recalls first

9 NHTSA recalls · 36 owner complaints on file

This year has the longest recall list of the e-tron run — nine campaigns. Two are critical: battery modules that can overheat and catch fire, and an overheating portable charging cable. Two separate brake booster problems appear, one corrosion-related that weakens braking. Several overlapping backup camera recalls and a glove box that can block the knee airbag round it out. A rear seat belt recall also affects child seat holding. Owners filed 36 unverified complaints, mostly electrical, with one reported fire and no crashes or injuries.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Run the VIN for open recalls — with nine campaigns, some are likely unfinished.
  3. Verify both brake booster recalls, including the corrosion one, were completed.
  4. If you carry a child seat, install it with the rear belt before buying.
  5. Open recalls are repaired free at any Audi dealer, whoever owns the car — an open recall is a to-do item, not a bill.
