Buying a used 2018 Audi A6? Check these 2 recalls first

2 NHTSA recalls · 2 owner complaints on file

This 2018 A6 carries two recalls: a critical fuel rail leak issue shared with A7 and Q7, and a high-severity seat sensor fault that can stop airbag deployment. NHTSA owner complaints total only 2, including one fire report and zero crashes or injuries; these are unverified owner accounts. Complaint areas are spread across electrical, fuel/propulsion, and air bags, one each. Recall completion status and any history of the reported fire should be confirmed before purchase.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm fuel rail leak recall (A6/A7/Q7) was completed
  3. Ask if the seat sensor airbag recall was performed
  4. Ask seller about any electrical, fuel system, or fire-related history
  5. Open recalls are repaired free at any Audi dealer, whoever owns the car — an open recall is a to-do item, not a bill.
