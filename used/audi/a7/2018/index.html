Buying a used 2018 Audi A7? Check these 2 recalls first

2 NHTSA recalls · 0 owner complaints on file

This 2018 A7 carries two recall items: a critical fuel rail leak concern and a high-severity seat sensor fault that can stop airbag deployment. NHTSA has no owner complaints on record for this model year. With no complaint history available, there is no owner-reported data to weigh here. Recall completion should be verified directly with the seller or a dealer, and a general inspection is worth doing given the absence of any complaint record to reference.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm fuel rail leak recall was completed
  3. Verify the seat sensor airbag recall was performed
  4. Ask seller directly about vehicle condition since no complaints are on file
  5. Open recalls are repaired free at any Audi dealer, whoever owns the car — an open recall is a to-do item, not a bill.
