Buying a used 2018 Audi A7? Check these 2 recalls first

2 NHTSA recalls · 0 owner complaints on file

The 2018 A7 shares its recall record with the A6: a fuel rail that can leak gasoline, rated critical, and a passenger airbag that may not deploy. No owner complaints are on record with NHTSA for this model year. That absence is not the same as a clean record — it means there is no complaint data to weigh, so the two recalls and a hands-on inspection are what you have to go on.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Ask for VIN documentation showing the fuel rail leak recall was completed.
  3. Confirm the passenger airbag recall repair was performed.
  4. Inspect the engine bay for fuel smell or staining, since no complaint data exists.
  5. Open recalls are repaired free at any Audi dealer, whoever owns the car — an open recall is a to-do item, not a bill.
