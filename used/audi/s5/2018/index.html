Buying a used 2018 Audi S5? Check these 2 recalls first

2 NHTSA recalls · 26 owner complaints on file

On recalls this is a light year, with two overlapping campaigns for the same passenger airbag shut-off problem and neither flagged stop-driving or park-outside. The complaint file is the notable part: 26 unverified owner reports, the largest count among the S5 years here, including two alleging crashes and one an injury. Engine leads with nine reports, followed by eight unclassified, three airbag and three visibility or wiper. These are owner allegations, not confirmed defects, but the engine cluster deserves attention.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Get a pre-purchase inspection focused on the engine, including a cold start and code scan
  3. Verify both passenger airbag recalls were completed and watch the occupancy light
  4. Run the wipers and washers through all speeds and check for erratic operation
  5. Open recalls are repaired free at any Audi dealer, whoever owns the car — an open recall is a to-do item, not a bill.
