Buying a used 2019 MINI Countryman? Check these 2 recalls first

2 NHTSA recalls · 11 owner complaints on file

Two open recalls: a crankshaft sensor fault that can stall the engine, and a missing fuel pump crash protection plate. Neither is flagged stop-driving or park-outside. Eleven unverified owner complaints sit with NHTSA — one crash, no fires or injuries — and engine is the largest group with four reports, which lines up with the stalling campaign. Air bags and fuel/propulsion each appear twice, alongside uncategorized reports.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Ask whether the crankshaft sensor recall was performed and if stalling ever occurred
  3. Confirm the fuel pump protection plate was installed
  4. Scan for stored engine and airbag fault codes before buying
  5. Open recalls are repaired free at any MINI dealer, whoever owns the car — an open recall is a to-do item, not a bill.
