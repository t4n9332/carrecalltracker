Buying a used 2019 RAM 4500? Check these 10 recalls first

10 NHTSA recalls · 6 owner complaints on file

Two themes run through this year: diesel fire and stall recalls shared with other heavy-duty Rams, and an unusual cluster of four separate rear brake hose or line campaigns, one tied to LiquidSpring suspension kits. A missed low-oil warning and breakable wheel studs are also listed. None carried stop-driving or park-outside instructions. Only six unverified owner complaints reached NHTSA, with no crashes, fires or injuries — too few to draw conclusions from on this low-volume chassis cab.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Ask which of the four brake hose and line recalls were performed, by VIN
  3. Check whether a LiquidSpring suspension kit is fitted, which triggers its own brake line recall
  4. Get documentation on the diesel fuel line, engine damage and stalling recall repairs
  5. Open recalls are repaired free at any RAM dealer, whoever owns the car — an open recall is a to-do item, not a bill.
