Buying a used 2018 RAM 4500? Check these 7 recalls first

7 NHTSA recalls · 9 owner complaints on file

Brakes define this year's record. Recalls cover corroding brake hoses, anti-lock brakes and stability control that can fail, cruise control that may stick on, trucks shifting out of park unexpectedly, and breakable wheel studs. Two campaigns are equipment-specific: faulty Kidde fire extinguishers and Excellance ambulance brake lights that turn on by themselves. Only nine unverified owner complaints are on file with NHTSA, all service brakes, five hydraulic, with no crashes, fires or injuries reported.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Have the rear brake hoses and lines inspected for corrosion, and ask if the recall was done
  3. Confirm the truck holds in park on a grade and that cruise control disengages cleanly
  4. Ask whether the truck was upfitted, which determines if the extinguisher or ambulance recalls apply
  5. Open recalls are repaired free at any RAM dealer, whoever owns the car — an open recall is a to-do item, not a bill.
