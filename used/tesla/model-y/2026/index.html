Buying a used 2026 Tesla Model Y? Check these 8 recalls first

8 NHTSA recalls · 1 owner complaints on file

The 2026 Model Y list covers washer spray, seat fasteners, horn operation, reverse lights, battery contacts, front suspension connections, and a missing certification label. Mechanical and electrical items merit repair records; the label item is administrative. One supplied entry names only Model 3 vehicles missing safety features, so its applicability to this Model Y needs verification. NHTSA has 1 owner complaint, an unverified vehicle-speed-control report, with 0 reported crashes, fires, or injuries. That complaint alone does not establish a defect.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Obtain a VIN recall report resolving the Model 3-only entry and certification label.
  3. Request seat-fastener, battery-contact, and front-suspension recall repair records.
  4. Test washers, horn, and reverse lights; ask about speed-control concerns.
  5. Open recalls are repaired free at any Tesla dealer, whoever owns the car — an open recall is a to-do item, not a bill.
