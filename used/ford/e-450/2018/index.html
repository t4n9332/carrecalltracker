Buying a used 2018 Ford E-450? Check these 4 recalls first

4 NHTSA recalls · 5 owner complaints on file

The 2018 E-450's recalls track how the chassis was upfitted: loose rear axle bolts on shuttle bus builds, ambulance brake lights that can illuminate on their own, and a back-up camera that may flip its image. The axle bolt recall is the highest severity of the group. Five unverified owner complaints are on file with NHTSA covering steering, equipment and suspension, with no crashes, fires or injuries. Which recalls apply depends on the specific body and VIN.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Run the VIN to see which body-specific recalls actually apply to this build
  3. Ask whether the rear axle bolt inspection was completed if it is a shuttle bus
  4. Test the back-up camera image and check brake lights stay off with the pedal released
  5. Open recalls are repaired free at any Ford dealer, whoever owns the car — an open recall is a to-do item, not a bill.
