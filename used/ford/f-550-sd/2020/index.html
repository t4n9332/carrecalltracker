Buying a used 2020 Ford F-550 SD? Check these 8 recalls first

8 NHTSA recalls · 4 owner complaints on file

Eight recalls, with the serious ones clustered on the diesel: a transmission part that can cause a stall, a failure to hold Park, and two separate fuel pump recalls including the high-pressure pump. Lower-severity items cover a windshield that may detach, wiper arms that can break, a blank backup camera, and a manual omission. None carry stop-driving instructions. Four owner complaints are on file with NHTSA — unverified — mostly fuel and power train, including one crash.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Ask whether the truck is a diesel, since most of the significant recalls apply only to diesels
  3. Get documentation on both fuel pump recalls and the transmission stall remedy
  4. Set the parking brake and test that it holds in Park on an incline
  5. Open recalls are repaired free at any Ford dealer, whoever owns the car — an open recall is a to-do item, not a bill.
