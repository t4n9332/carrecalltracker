Buying a used 2018 Ford Flex? Check these 3 recalls first

3 NHTSA recalls · 65 owner complaints on file

This model year has three recalls: a high-severity recall for a rear toe link that may fracture, a high-severity recall for door trim detachment risk, and a medium-severity recall for a rearview camera that may show a blank image. NHTSA has logged 65 owner complaints (unverified) for this model year, including 7 crashes and 1 injury, with no reported fires; the top complaint areas are structure (18), unknown or other (17), back-over prevention (14), and electrical system (11).

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm the rear toe link recall has been completed
  3. Inspect door trim for detachment or looseness
  4. Test the rearview camera and check for electrical system issues
  5. Open recalls are repaired free at any Ford dealer, whoever owns the car — an open recall is a to-do item, not a bill.
