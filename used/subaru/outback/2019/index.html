Buying a used 2019 Subaru Outback? Check these 3 recalls first

3 NHTSA recalls · 1,033 owner complaints on file

Two separate fuel pump recalls apply, both for stalling while driving, plus a medium-severity recall for potentially weak body welds. None carries a stop-driving or park-outside warning. This year has the largest complaint file among these Outbacks: 1,033 unverified NHTSA reports, with 24 crashes, two fires and 18 injuries. Electrical system and visibility/wiper dominate those reports, together making up the majority of the total.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Check both fuel pump recalls by VIN and ask which remedy was actually performed
  3. Ask whether the body weld recall inspection was done and what the result was
  4. Test wipers, lighting and all electrical accessories, the top two complaint areas
  5. Open recalls are repaired free at any Subaru dealer, whoever owns the car — an open recall is a to-do item, not a bill.
