Buying a used 2018 Subaru Outback? Check these 3 recalls first

3 NHTSA recalls · 811 owner complaints on file

This model year has one high-priority recall for a fuel pump that may fail, plus two medium-priority recalls for a fuel gauge software error and a backup camera screen that may stay blank. NHTSA has recorded 811 owner complaints, including 27 crash reports, 4 fire reports, and 19 injury reports — unverified owner accounts. The most common complaint areas are electrical system (265), visibility/wiper (233), unknown or other (160), and fuel/propulsion system (43).

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Verify the fuel pump recall has been completed
  3. Ask whether the fuel gauge software update was applied
  4. Test the backup camera and ask about electrical system issues
  5. Open recalls are repaired free at any Subaru dealer, whoever owns the car — an open recall is a to-do item, not a bill.
