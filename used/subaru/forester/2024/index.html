Buying a used 2024 Subaru Forester? Check these 2 recalls first

2 NHTSA recalls · 29 owner complaints on file

Two open safety recalls define this year: a coolant leak that can start an engine fire, and a front driveshaft that can break. Neither carries a stop-driving or park-outside instruction, but both are repairs worth seeing documented. Complaint volume is modest at 29 unverified owner reports filed with NHTSA, though those include four crashes, one fire and one injury. Air bags lead the named complaint areas, followed by wiper/visibility and forward collision avoidance.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Run the VIN and confirm the coolant leak/fire recall repair is complete
  3. Ask whether the front driveshaft recall was performed, and by which dealer
  4. On the test drive, check wipers, defroster and any EyeSight warning messages
  5. Open recalls are repaired free at any Subaru dealer, whoever owns the car — an open recall is a to-do item, not a bill.
