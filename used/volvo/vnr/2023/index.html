Buying a used 2023 Volvo VNR? Check these 3 recalls first

3 NHTSA recalls · 1 owner complaints on file

Most of this year's recall exposure is specific to the VNR Electric: a critical battery coolant leak that can cause fire, and a high-severity fault where the truck brakes hard on its own. A medium recall covers a wiper motor that can quit working. None carry stop-driving or park-outside instructions. One owner complaint is on file with NHTSA, logged under unknown or other, with no crashes, fires, or injuries; complaints are unverified reports.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Confirm whether this is an Electric model, and if so that the battery coolant leak recall was completed
  3. Ask the seller about any unexpected hard braking events and whether that recall remedy was applied
  4. Test the windshield wiper motor and check for the wiper recall on the VIN report
  5. Open recalls are repaired free at any Volvo dealer, whoever owns the car — an open recall is a to-do item, not a bill.
