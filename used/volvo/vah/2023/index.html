Buying a used 2023 Volvo VAH? Check these 4 recalls first

4 NHTSA recalls · 1 owner complaints on file

This is a heavy truck, so the record reads like commercial equipment rather than a passenger car. Four recalls apply: loose steering gear bolts, a loss of electronic safety systems shared with VN models, a passenger seat belt anchor that may fail, and a windshield wiper motor that can quit. Three are rated high, and none carry a stop-driving or park-outside instruction. Only one unverified owner complaint is on file with NHTSA, under power train, with no crashes, fires, or injuries.

Before you buy

  1. Get the 17-character VIN from the seller and run it at nhtsa.gov/recalls. It shows which recalls are still unrepaired on that exact car.
  2. Have the steering gear bolts inspected and torque-verified, and get the recall status by VIN.
  3. Confirm the electronic safety systems recall update was applied and the systems power up without fault lamps.
  4. Inspect the passenger seat belt anchor and run the wipers through all speeds.
  5. Open recalls are repaired free at any Volvo dealer, whoever owns the car — an open recall is a to-do item, not a bill.
